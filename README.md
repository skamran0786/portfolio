## About

I'm building practical skills across IT support, computer troubleshooting, networking, CCTV systems, and web development. This repository contains the source files for my personal portfolio website.

## Website Features

- Responsive portfolio layout for desktop and mobile
- Sections presenting my profile, skills, projects, and contact details
- Custom styling and client-side interactions
- SEO-related files, including `robots.txt` and `sitemap.xml`

## Built With

- HTML5
- CSS3
- JavaScript
- SVG assets

## Project Structure

| Path | Purpose |
| --- | --- |
| `index.html` | Main portfolio page |
| `style.css` | Website styling and responsive layout |
| `script.js` | Main client-side interactions |
| `fluid.js` | Visual/fluid effect script |
| `assets/` | Supporting website assets |
| `logo.svg` | Vector logo |
| `robots.txt` | Search-engine crawling instructions |
| `sitemap.xml` | Sitemap for the website |
| `vercel.json` | Vercel deployment configuration |

## Run Locally

Because this is a static front-end website, no package installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/skamran0786/portfolio.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use the VS Code Live Server extension for a local development server.
